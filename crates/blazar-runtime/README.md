# blazar-runtime

Runtime layer of the [blazar](https://github.com/santanu20/blazar) local
inference platform: engine installation and upgrades (llama.cpp, mistral.rs,
SGLang, MLX, whisper, piper, stable-diffusion), the Hugging Face download
client with resume and integrity verification, the process supervisor, the
event bus, and the benchmark runner.

Part of the `blazar` workspace; see the
[main README](https://github.com/santanu20/blazar) for the full platform.
