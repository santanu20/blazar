# blazar-gateway

HTTP gateway of the [blazar](https://github.com/santanu20/blazar) local
inference platform: OpenAI- and ollama-compatible chat/completions/embeddings
endpoints, SSE streaming, server-sent job events, metrics aggregation, and
the priority request queue with cancellation and interrupt cards.

Part of the `blazar` workspace; see the
[main README](https://github.com/santanu20/blazar) for the full platform.
