# 6. BUSINESS RULES

> Verified against Blazar v0.6.1 source. **INFERRED** tags mark reasoned statements.

## Role → permission mapping

| Role | How acquired | Permissions |
|---|---|---|
| Anonymous (local) | Default — no `[[keys]]` configured | Full model access on all APIs; NO key management (gateway refuses: 403 `no keys configured: add the first [[keys]] entry in config.toml (or BLAZAR_KEYS env) and restart`) |
| Scoped key | `[[keys]]` entry with non-empty `models` | Generation on its scoped models only; no key management |
| Admin key (unscoped) | `[[keys]]` entry with empty `models` | All models + key management (`/api/keys` add/remove/rotate/list) |
| Remote upstream | `[[remotes]]` entry | Receives routed `<remote>:<model>` requests with its optional upstream key |

## Time-based rules

| Rule | Value |
|---|---|
| Idle eviction | `idle_timeout_secs` 1800 default; `idle_sleep_secs` 300 |
| `keep_alive` semantics | N seconds / 0 = unload immediately / -1 = keep forever; honored from both OpenAI and ollama APIs; `/api/ps` shows countdown |

| Key usage accounting day | UTC `YYYY-MM-DD` boundary |

| Hint task cadence | 60 s (EWMA 0.7/0.3) |
| OTLP export cadence | 10 s bounded batches |

## Conditional logic and edge cases

- **Auth activation is data-driven**: zero keys → open gateway; ≥1 key → everything except `/healthz`+`/health` requires a valid secret.
- **Concurrency lease ordering**: `max_concurrent` gate runs BEFORE scope/rpm/tpm; the lease is held until the response body drains (a held SSE stream occupies a slot — bounded by design).
- **Engine routing matrix**: quantized safetensors (AWQ/GPTQ/FP8) → SGLang only, never a mistral.rs fallback (its dequant path is known-broken upstream v0.9.3); GGUF → llama.cpp then mistral.rs; plain safetensors → by policy (Quality/Throughput: SGLang first; Latency: mistral.rs first); diffusion component sets (rows with a flag-keyed `components` list, e.g. `--vae`+`--llm`) → `sdcpp` only (`DiffusionUnserved` teaching names the install command when absent), and no text row ever routes to `sdcpp`. Model-level `engine` override beats both routing modes. Within a kind, mainstream engines outrank fork lanes regardless of install recency — a capability fork only receives architectures mainstream lacks; an unknown-architecture death re-routes once to an advertising lane (pin remembered), then teaches.
- **Fork-lane retirement**: a lane is stamped superseded only on full architecture coverage upstream, and only curated lanes auto-delete (`fork_retire_days`, default 7; 0 = never). User-built forks and lanes protected by a model pin are never auto-deleted; retirement warns and names the registry rebuild path.
- **Colon semantics**: `owner/repo:QUANT` for pulls; `model:tag` at request time resolves onto existing flat rows only (colon→dash swap if that row exists; miss = name verbatim).
- **Replica keys**: `model#N` instance keys are internal; the store rejects `#` in user-facing names.
- **Vision grammars**: `@vision` suffixed instance keys exist alongside plain/replica keys; `evict_model` releases pins and evicts every grammar.
- **Determinism tradeoff**: `deterministic = true` forces `slots = 1` — multi-slot serving perturbs near-tie logits (greedy probes flip).
- **Thinking-template gating**: `think == Some(true)` on a template without thinking markers → teaching 400 (fail-open if markers unreadable); absent `think` on marker-carrying templates → `think:false` injected (local lane only, before translation).
- **reasoning_effort bridge**: chat completions only (completions/responses excluded); Anthropic `thinking` maps into `chat_template_kwargs`.
- **Stream rendering**: TTY chat renders thinking inline dimmed; piped output omits it.
- **Singleflight**: duplicates ride the leader's warm prefix (non-stream only).
- **Semantic cache bypass**: streams bypass; structured-output requests bypass in BOTH directions; embed-model failures bypass (never block generation); never shared across API keys.
- **Warm pegs**: SGLang peg is BLOCKING, llama.cpp peg DETACHED (fire-and-forget, bounded 90 s + 60 s), mistral.rs and sdcpp never peg.
- **Clean vs unclean child death**: clean teardown resets crash history; SIGKILL-after-grace on a sleeping child logs a cosmetic "engine crashed (signal 9)" ERROR that is breaker-safe (documented misclassification).
- **XDG fallback**: when XDG dirs are unavailable the tool falls back to CWD with a loud stderr warning.

## Rules enforced ONLY on the backend (gateway/runtime)

All of the above are backend-enforced; clients cannot opt out of: auth activation, quota ordering, queue discipline (priority/EDF/WFQ), preflight refusals, routing matrix (no client-selected engine except configured `pin`/`engine` override), eviction/session-bank lifecycle, circuit breakers, sentinel observation (bytes never altered regardless of `sentinel_enforce`), audit identity capture, quantized-safetensors lane protection, `#`-in-name rejection, key persistence round-trip (atomic write + `.bak` + rollback), last-key protection, anonymous-gateway management refusal.
