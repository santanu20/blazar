# 9. USAGE

> End-user operations guide for Pallama v0.6.1. Companion docs: `1.SYSTEM_OVERVIEW.md` (what it is), `4.API_SPEC.md` (full HTTP+CLI reference), `7.SETUP.md` (env/config).

## Installation

| Platform | Method |
|---|---|
| Linux / macOS | `curl -fsSL <published-repo>/install.sh \| sh` (override source with `PALLAMA_REPO`) |
| Windows | `winget install pallama` (rustup provisioned via winget) or `scripts/install.ps1` |
| Package managers | Homebrew, Scoop (see `packaging/`) |
| From source | `git clone` → `cargo build --release` (zero-arg build works; `scripts/bootstrap.sh --minimal` provisions toolchain first) |

## Quickstart (copy-paste)

```sh
pallama engine update                 # install official llama.cpp engine (sha256-verified)
pallama pull qwen3-0.6b               # pull a model (registry shortname)
pallama serve &                       # start the gateway on 127.0.0.1:11435
curl http://127.0.0.1:11435/v1/chat/completions \
  -H 'Content-Type: application/json' \
  -d '{"model":"qwen3-0.6b","messages":[{"role":"user","content":"hello"}]}'
pallama run qwen3-0.6b                # interactive chat REPL
```

Existing ollama clients work after re-pointing: `OLLAMA_HOST=http://127.0.0.1:11435 ollama list` (or set `port = 11434` in `config.toml` for a drop-in once ollama is removed).

## Common tasks

| Goal | Commands | Expected result |
|---|---|---|
| Install/upgrade an engine | `pallama engine update` (or `--kind sglang` / `--kind mistralrs`) | engine downloaded, verified, regression-gated; auto-rollback on >10% decode drop |
| Build CUDA engine locally | `pallama engine build cuda` | local build with auto GPU-arch + host-compiler matching; `llama-server` + tooling installed under a `bNNNN-cuda`-style tag |
| Switch engines | `pallama engine use <tag>` or `--kind <kind>`; `pallama engine list` | active engine switches; auto routing stays default |
| Rollback an engine | `pallama engine rollback` | previous tag re-activated |
| Pull from HF | `pallama pull ggml-org/Qwen3-8B-GGUF:Q4_K_M` | `owner/repo:QUANT` resolved, sha256-verified, resumable |
| See what fits before downloading | `pallama fit <target>` | VRAM fit preview + quant alternatives (+ lane hint for safetensors) |
| Register a local GGUF | `pallama import /path/to/model.gguf --name mymodel` | model usable without copying (or `--copy`) |
| List / inspect models | `pallama list` / `pallama show <model>` (`--json` for JSONL) | flat model rows, quants, sizes |
| Check what's running | `pallama ps` | instances with slots/ctx/ports/in-flight + keep-alive countdown |
| Load/unload now | `pallama stop <model>`; or request with `keep_alive: 0` / `-1` | immediate unload / keep forever |
| Save session across unload | `pallama session save <model>` … `pallama session restore <model>` | KV checkpoint survives unload + restarts (also automatic via session bank) |
| Tune performance | `pallama tune <model>` (`--search`, `--slots`, `--spec`, `--load`, `--replicas`, `--cache-reuse`) | best argv recorded into `profiles` |
| Benchmark | `pallama bench <model>` | tg/pp tokens/s recorded into `bench_history` |
| Add API keys | `pallama keys add` or edit `[[keys]]` in `~/.config/pallama/config.toml` | gateway starts requiring `Authorization: Bearer plm_...` / `x-api-key` |
| Debug a bad response | `pallama why` (or `/api/why`) with the trace id | sentinel detections + routing trail (PII-scrubbed if `pii_scrub`) |
| Health check | `pallama doctor` | grouped SYSTEM/GPU/ENGINES/MODELS/CHANNELS/RUNTIME findings with fixes |
| Transcribe audio | `pallama whisper file.wav --model <size>` | transcription via the whisper lane |
| Point an agent CLI at Pallama | `pallama launch <command>` | OpenAI/Anthropic/ollama base-URL env set, daemon ensured, command exec'd |

## Every way a user invokes Pallama

1. **CLI `pallama`** — full command surface (see `4.API_SPEC.md` CLI table: serve/run/pull/import/list/show/ps/rm/create/cp/push(refused)/keys/quantize/bench/tune/launch/engine/lora/search/fit/config/upgrade/session/doctor/why/watch/snapshot/migrate/mmproj/drafts/coreside/whisper/stop/completions + refused signin/signout/login/logout).
2. **HTTP gateway** — OpenAI (`/v1/*`), ollama (`/api/*`), Anthropic (`/v1/messages`) endpoints on `127.0.0.1:11435`; see `4.API_SPEC.md`.
3. **Existing clients** — any OpenAI SDK / ollama CLI / Anthropic SDK by setting base URL (ollama: `OLLAMA_HOST`).
4. **Direct model files** — weights under `~/.local/share/pallama/models/` are plain `.gguf`/safetensors, usable by external tools.

## Configuration an end user can set

Managed via `~/.config/pallama/config.toml` or `pallama config set <key> <value>` (dotted keys; quoted segments stay one segment). Highlights — see `7.SETUP.md` for the full switch table:

- Serving: `host`, `port`, `default_ctx`, `max_loaded_models`, `slots`, `deterministic`
- Memory/quality: `cache_type`, `kv_unified`, `cache_ram_mb`, `ctx_extend` (YaRN), `load_mode`
- Behavior: `spec`, `session_bank`, `singleflight`, `prompt_preflight`, `sentinel*`, `semantic_cache.*`, `audit_log`
- Access: `[[keys]]`, `tls_cert`/`tls_key`, `cors_origins`, `[[remotes]]`
- Routing: `engine_routing.mode/policy`, `model_overrides.<model>.engine`, `.pin`, `.replicas`
- Networking/observability: `otlp_endpoint`, `otlp_service`

## Troubleshooting / FAQ

| Symptom | Cause → fix |
|---|---|
| Port already in use at startup | another server (e.g. ollama on 11434) → set `port` in config or stop the other service; Pallama exits 3 by design instead of restart-looping |
| 401 `missing or invalid API key` | keys configured → send `Authorization: Bearer <plm-key>` or `x-api-key` |
| 403 `no keys configured` on `/api/keys` | key management needs at least one `[[keys]]` entry first |
| 409 removing a key | it's the last key — the gateway refuses to go authless |
| 503 `all_slots_busy` | all slots saturated → wait, raise `slots`/`max_loaded_models`, or send `x-pallama-priority: high` for urgent work |
| 502 with engine message | child failed mid-request; the next request auto-respawns — if persistent, `pallama doctor` |
| 400 teaching error naming an install command | model needs an engine lane → `pallama engine install --kind <kind>` |
| 400 prompt refused (preflight) | prompt cannot fit ctx → raise `ctx`/`num_ctx`, quantize KV (`cache_type`), or pull a smaller quant (`pallama fit`) |
| 422 `sentinel enforce` | response failed quality gate (schema/truncation/empty) with `sentinel_enforce` on → fix prompt/schema or disable enforce |
| Model slow to first token after idle | cold reload — consider `warm_peg` / `keep_alive: -1` / session bank |
| `pallama run` eats my prompt as flags | flags must precede the prompt; quote leading `-` or use `--` |
| Weird model name errors containing `#` | `#` is reserved (replica keys) — rename without it |
| XDG warning on stderr at startup | XDG dirs unavailable → running with CWD fallback (deliberately loud) |
